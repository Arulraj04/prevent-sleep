# ☕ Prevent Sleep

A lightweight Windows desktop app that keeps your system awake and prevents idle-based sleep, screen lock, or logout — especially useful on domain-managed/corporate PCs with short idle timeouts.

## 📥 Download

👉 **[Download the latest release](../../releases/latest)**

## ✨ Features

| Feature | Description |
|---|---|
| 🟢 **Prevent Sleep (ON/OFF)** | Keeps Windows from going idle using the native Windows API |
| 📊 **Live Status Dashboard** | Shows current status, active power plan, and last activated time |
| ⏱ **Timer Options** | Run for 30 minutes, 1 hour, or until manually stopped |
| ⏳ **Live Countdown** | See exactly how much time is left when a timer is running |
| 😴 **"Active For" Tracker** | Tracks continuous active time, with a friendly nudge to take a break after a few hours |
| 🚀 **Start with Windows** | Optional auto-launch on login |
| 🖥 **Runs in System Tray** | Stays out of your way — double-click the tray icon to reopen |
| ❤️ **Support the Developer** | Built-in scan-to-pay donation QR code |

## 🚀 Getting Started

1. Go to the [Releases](../../releases) page
2. Download `StatusApp.exe` from the latest release
3. Run it — the app starts minimized in your system tray
4. Double-click the tray icon to open the dashboard
5. Toggle **Prevent Sleep** ON and pick a duration

> ⚠️ Windows SmartScreen may show an "Unrecognized publisher" warning the first time, since this app isn't code-signed. Click **More info → Run anyway** to proceed.
